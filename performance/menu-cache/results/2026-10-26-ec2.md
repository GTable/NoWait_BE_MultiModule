# EC2 측정 원본 (2026-10-26 22:26 ~ 22:48)

실행 조건
- 인스턴스: db c7g.large, app c7g.xlarge, k6 c7g.large (서울, 같은 서브넷, Ubuntu 24.04 Arm). 쿠폰 프로젝트 실험용 인스턴스를 중지했다 다시 켠 뒤 썼다
- MySQL 8.0.36 (1 CPU / 1GB), Redis 7.2 (1 CPU / 1GB). 쿠폰 프로젝트 컨테이너를 그대로 쓰고 스키마만 `nowait_lab` 으로 나눴다(측정 후 삭제)
- user-api·admin-api: `-Xms256m -Xmx512m -XX:+UseG1GC`, `user-local`·`admin-local` 프로필, SQL 로그 끔, Discord 웹훅 막음
- 데이터: 주점 200, 메뉴 4,000, 이미지 4,000, 관리자 1 (`seed.sql`, 주점 수 `STORES=200`)
- 트래픽: 손님 메뉴 목록 조회만(`LIST_RATIO=1`) + 품절 토글 초당 1건(`WRITE_RATE=1`). 단계마다 초당 100건 20초 예열을 버리고, 속도마다 60초 1회
- 표의 열: 처리 req/s·지연·실패·못 보낸 요청은 k6 조회 시나리오만. stores·menus·menu_images 는 그 테이블 쿼리 호출 수(`performance_schema` digest, admin 쿼리 포함). MySQL CPU 는 컨테이너 cgroup, user-api CPU 는 JVM 누적 CPU 시간에서 계산한 코어 수
